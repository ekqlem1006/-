# 설교 프롬프터

설교문과 PPT 를 태블릿 한 화면에서 보면서, 설교자가 예배용 윈도우 컴퓨터의 **실제 파워포인트 슬라이드 쇼**를 직접 넘기는 프로그램입니다.

```
컴퓨터에서 SermonPrompter.exe 실행 → 태블릿 카메라로 QR 스캔 → 연결 완료
```

- 설치할 것 없음: 실행 파일 하나(`SermonPrompter.exe`)만 있으면 됩니다. Python·명령어·IP 입력이 필요 없습니다.
- 태블릿에는 앱을 깔지 않습니다. QR 을 찍으면 Safari / Chrome / 삼성 인터넷에서 바로 열립니다.
- 인터넷이 없어도 됩니다. 컴퓨터와 태블릿이 같은 공유기(와이파이)에만 있으면 됩니다.

> ⚠ **현재 상태**: 대본 자동 연결, 화면 흐름, 조작 권한, 저장·복원, 끊김 후 재연결은 가상 PPT 로 자동 시험을 통과했습니다.
> 그러나 **실제 윈도우 + 파워포인트 + 아이패드/갤럭시 조합은 아직 한 번도 돌려 보지 못했습니다.**
> 아래 [현장 확인표](#현장-확인표)를 실제 기기로 확인하기 전에는 완료로 보지 말아 주세요.

## 받기

GitHub 저장소의 **Actions → 「설교 프롬프터 빌드」 → 가장 최근 실행 → Artifacts → `SermonPrompter-windows`** 를 내려받아 압축을 풀면 `SermonPrompter.exe` 가 나옵니다. 예배용 컴퓨터의 바탕 화면 등 아무 곳에나 두면 됩니다.

처음 실행할 때 윈도우가 두 번 물어볼 수 있습니다.

1. **「Windows 의 PC 보호」** (파란 창): 「추가 정보」 → 「실행」. (서명되지 않은 프로그램이라 뜨는 안내입니다.)
2. **「Windows 보안 경고 — 방화벽」**: **「액세스 허용」**. 태블릿이 이 컴퓨터에 접속하려면 꼭 필요합니다. 놓쳤다면 연결 화면의 「방화벽에서 이 프로그램 허용하기」 버튼을 누르면 됩니다.

## 쓰는 순서

### 준비 (주중, 한 번만)

1. 예배용 컴퓨터에서 예배 PPT 를 파워포인트로 엽니다.
2. `SermonPrompter.exe` 를 실행합니다. 브라우저에 **연결 화면(QR)** 이 자동으로 열립니다.
3. 연결 화면의 「이 컴퓨터에서 대본 준비하기」를 누르거나, 태블릿으로 QR 을 찍습니다. (어느 쪽에서 준비해도 같은 내용이 컴퓨터에 저장됩니다.)
4. **대본 넣기**: 설교 대본 전체를 붙여 넣습니다. `▶ 1 · 제목` 표시가 있는 줄마다 슬라이드 구간으로 자동으로 나뉩니다. (`**▶ 1 · 제목**` 처럼 굵게 표시되어 있어도 됩니다.)
5. **시작 슬라이드 지정**: 전체 예배 PPT 미리보기에서 대본 1번에 해당하는 슬라이드(예: 20번)를 한 번 누르면, 2번→21번, 3번→22번… 순서대로 연결됩니다.
6. 중간에 다른 슬라이드가 끼어 있으면 그 구간의 「변경」만 눌러 고칩니다.

저장 버튼은 없습니다. 고칠 때마다 예배용 컴퓨터에 자동 저장되고, 같은 PPT 를 다시 열면 그대로 불러옵니다.

### 예배 당일

1. 방송실: 평소처럼 예배 PPT 를 열고 슬라이드 쇼를 진행합니다. `SermonPrompter.exe` 를 켜 둡니다.
2. 설교자: 태블릿에서 QR 을 찍습니다(한 번 연결한 태블릿은 저장해 둔 주소로 다시 들어가도 됩니다). 준비한 대본이 바로 뜹니다.
3. 설교 직전 **「설교 조작 시작」** 을 누릅니다. 이 버튼만으로는 예배 화면이 바뀌지 않습니다.
4. 오른쪽(세로 화면에서는 아래)의 슬라이드를 누르거나 **「다음」** 을 누르면, 설교문이 그 구간으로 이동하고 **실제 파워포인트도 그 슬라이드로 넘어갑니다.**
5. 칠판 설명 때는 **「검은 화면」** → 끝나면 **「화면 복귀」**. 가린 채로 다음 슬라이드를 고르면 가림이 풀리면서 넘어갑니다.
6. 설교가 끝나면 **「설교 조작 종료」**. 방송실에서 다음 순서를 이어갑니다.

| 화면 표시 | 뜻 |
| --- | --- |
| 회색 줄 「미리보기」 | 슬라이드를 눌러도 설교문만 움직입니다. 예배 화면은 그대로입니다. |
| 빨간 줄 「송출 조작 중」 | 슬라이드를 누르면 예배 화면이 실제로 바뀝니다. |
| 빨간 테두리 「송출 중」 | 지금 예배 화면에 떠 있는 슬라이드입니다. 방송실에서 직접 넘겨도 따라 바뀝니다. |
| 맨 위 빨간 띠 「연결이 끊겼습니다」 | 와이파이가 끊겼거나 컴퓨터의 프로그램이 꺼졌습니다. 돌아오면 자동으로 다시 연결됩니다. |

## 동작 방식과 약속

- **설교 구간 밖으로 나가지 않습니다.** 태블릿은 대본에 연결된 슬라이드로만 이동시킵니다. 마지막 구간에서 「다음」을 눌러도 뒤의 헌금·광고로 넘어가지 않습니다. 현재 슬라이드에 클릭 애니메이션이 남아 있으면 「다음」은 그 애니메이션을 먼저 진행합니다.
- **방송실 조작을 막지 않습니다.** 프로그램은 실행 중인 파워포인트에 필요한 순간에만 연결하고, 파워포인트를 붙잡아 두지 않습니다. 키보드·마우스로 평소처럼 넘길 수 있습니다.
- **부서끼리 섞이지 않습니다.** 태블릿은 QR 을 찍은 그 컴퓨터에만 연결됩니다. 유년부 컴퓨터의 QR 로 연결한 태블릿은 유년부 컴퓨터의 PPT 만 조작합니다. 태블릿 맨 위에 연결된 컴퓨터(부서 이름)와 PPT 파일 이름이 항상 보입니다. 부서 이름은 연결 화면에서 정합니다.
- **한 번에 한 태블릿만 조작합니다.** 다른 태블릿은 미리보기만 할 수 있고, 확인을 거쳐 권한을 가져올 수 있습니다. 컴퓨터의 연결 화면에서 권한을 회수할 수도 있습니다.
- **PPT 를 고쳐도 연결이 유지됩니다.** 연결은 슬라이드 번호가 아니라 파워포인트의 슬라이드 고유 ID 로 저장합니다. 앞에 광고를 추가해 번호가 밀려도 같은 슬라이드를 찾아갑니다. 연결했던 슬라이드가 삭제되면 그 구간에 「확인 필요」가 표시됩니다.
- **검은 화면은 버튼으로만** 켜고 끕니다. 설교문을 스크롤한다고 켜지지 않습니다. 대본의 `(B키로 검은 화면)` 같은 진행 지시는 주황색으로 구분해 보여 줄 뿐, 자동으로 실행하지 않습니다.
- 슬라이드 쇼는 방송실에서 시작하는 것이 기본입니다. 쇼가 꺼진 상태에서 조작 중인 태블릿이 슬라이드를 누르면, 쇼를 시작할지 먼저 묻습니다.
- 슬라이드 내용을 고친 뒤 미리보기 그림이 옛것이면 준비 화면의 「PPT 다시 읽기」를 누릅니다.

저장 위치: `%APPDATA%\SermonPrompter\` (`sermons.json` = 대본과 연결, `config.json` = 부서 이름·연결 키·포트). 포트(기본 8765)와 연결 키는 한 번 정해지면 유지되므로, 컴퓨터의 내부 주소가 바뀌지 않는 한 태블릿에 저장한 주소를 계속 쓸 수 있습니다.

## 태블릿 설정 도움말

- 설교 중 화면이 꺼지지 않도록 **자동 잠금을 길게(또는 「안 함」)** 설정해 주세요. (아이패드: 설정 → 디스플레이 및 밝기 → 자동 잠금 / 갤럭시: 설정 → 디스플레이 → 화면 자동 꺼짐 시간) 화면이 꺼졌다 켜져도 자동으로 다시 연결되고 조작 권한도 유지됩니다.
- 브라우저의 「홈 화면에 추가」를 해 두면 다음부터 앱처럼 바로 열 수 있습니다.
- 블루투스 키보드/리모컨의 →, ↓, 스페이스는 「다음」, ←, ↑ 는 「이전」으로 동작합니다.

## 현장 확인표

실제 윈도우 컴퓨터 + 파워포인트 + 아이패드·갤럭시 태블릿으로 확인합니다. **1·2번(네트워크 연결)을 가장 먼저** 확인해 주세요. 이전 앱에서 `ERR_TOO_MANY_RETRIES` 가 났던 부분입니다.

| # | 확인할 것 | 아이패드 | 갤럭시 |
| --- | --- | --- | --- |
| 1 | exe 실행 후 QR 연결 화면이 자동으로 열린다 | ☐ | ☐ |
| 2 | QR 을 찍으면 주소·코드 입력 없이 접속되고, 연결 화면에 「태블릿 연결됨」이 뜬다 | ☐ | ☐ |
| 3 | 예시 대본을 넣으면 슬라이드별 설교문으로 자동으로 나뉜다 | ☐ | ☐ |
| 4 | 전체 예배 PPT 에서 시작 슬라이드만 지정해 설교 구간이 연결되고, 미리보기 그림이 실제 슬라이드와 같다 | ☐ | ☐ |
| 5 | 「설교 조작 시작」 후 슬라이드를 누르면 설교문과 실제 PPT 가 함께 이동한다 (마지막에서 「다음」은 넘어가지 않음) | ☐ | ☐ |
| 6 | 「검은 화면」과 「화면 복귀」가 실제 송출 화면에서 동작한다 | ☐ | ☐ |
| 7 | 다른 부서 컴퓨터에도 프로그램을 켠 상태에서, 조작이 내 컴퓨터에만 전달된다 | ☐ | ☐ |
| 8 | 와이파이를 껐다 켜거나 태블릿을 잠갔다 풀면, 끊김 표시 후 자동으로 다시 연결된다 | ☐ | ☐ |
| 9 | 프로그램과 파워포인트를 껐다 다시 켜도 준비 내용이 그대로 나온다 | ☐ | ☐ |
| 10 | PPT 앞에 슬라이드를 한 장 추가해도 연결이 유지된다 | ☐ | ☐ |

안 되는 항목이 있으면 `%APPDATA%\SermonPrompter\log.txt` 와 함께 어떤 화면에서 무엇이 보였는지 알려 주세요.

### 접속이 안 될 때 (2번)

1. 태블릿이 LTE/5G 가 아니라 컴퓨터와 **같은 공유기의 와이파이**에 연결되어 있는지 확인합니다.
2. 연결 화면의 「방화벽에서 이 프로그램 허용하기」를 누릅니다.
3. QR 아래에 주소가 여러 개 보이면(유선+무선, 가상 네트워크 등) 다른 주소로 바꿔 다시 찍습니다.
4. 손님용(게스트) 와이파이는 기기끼리의 연결을 막는 경우가 많습니다. 일반 와이파이를 씁니다.

## 개발

```bash
cd sermon-prompter
node logic_test.js                       # 대본 자동 연결 로직 시험
go build -o sp . && ./sp -sim            # 파워포인트 없이 가상 PPT 로 실행 (화면 흐름 확인용)
GOOS=windows GOARCH=amd64 go build -ldflags "-H=windowsgui -s -w" -o dist/SermonPrompter.exe .
```

| 파일 | 역할 |
| --- | --- |
| `main.go`, `server.go`, `store.go` | 내장 웹 서버, QR, 조작 권한, 저장 |
| `ppt_windows.go` | 실행 중인 PowerPoint 를 COM 자동화로 조작 (GotoSlide, 검은 화면, 미리보기 내보내기, SlideID) |
| `ppt_sim.go` | 개발·시험용 가상 PPT (`-sim`) |
| `web/logic.js` | 대본 나누기, 순서대로 연결, 고유 ID 로 복원 |
| `web/app.js`, `web/index.html` | 태블릿/컴퓨터 공용 화면 (준비 · 설교) |
| `web/host.html`, `web/host.js` | 예배용 컴퓨터의 QR 연결 화면 |
| `e2e_test.js` | 가상 PPT 로 화면 흐름 전체를 자동 시험 (Playwright) |

음성 인식 자동 넘기기, 설교문 자동 작성, PPT 자동 제작은 범위에 넣지 않았습니다.
